# Gömrük İmtahanı — Android tətbiqi

Gömrük qanunvericiliyi imtahanına hazırlıq: 29 sənəd, 2017 test sualı, 510 real imtahan sualı. İnternetsiz işləyir.

APK hər push-dan sonra avtomatik yığılır və **Releases** bölməsində `GomrukImtahani.apk` kimi dərc olunur.
Tətbiqin özü `app/src/main/assets/index.html` faylındadır.

**iPhone:** Safari-də https://eltacresidzadee-blip.github.io/Atlas/gomruk/ açın → Paylaş → Ana ekrana əlavə et.
